# NØRD Discord-бот

Что делает:
- **`/post`**: участник присылает фото (и необязательно текст). Бот публикует предложение в канале предложений с кнопками **«Принять в Медиа» / «Отклонить»**. Принятое фото автоматически попадает в раздел «Медиа» на сайте (категория «Предложения», автор: позывной с сайта, если аккаунт привязан).
- **`/link`**: привязка аккаунта сайта к Discord.
- **Синхронизация ролей**: когда на сайте выдают или снимают роль, бот меняет роль в Discord (проверка каждые 15 секунд, сразу после `/link` тоже).

| Роль на сайте | Роль в Discord |
|---|---|
| Администратор | `ROLE_FIGHTER_ID` и `ROLE_ADMIN_ID` |
| Боец отряда | `ROLE_FIGHTER_ID` |
| Заявка одобрена, но не боец | `ROLE_APPROVED_ID` (необязательно) |
| Обычный пользователь | ничего |

Бот трогает только роли, указанные в `.env`. Остальные роли человека не затрагиваются. Если человек отвязал Discord на сайте, эти роли снимаются.

## Установка
1. Нужен Node.js 18.17 или новее.
2. [Discord Developer Portal](https://discord.com/developers/applications): New Application → вкладка **Bot** → Reset Token (скопируйте токен). Привилегированные интенты (Presence, Server Members, Message Content) включать **не нужно**.
3. Приглашение бота: OAuth2 → URL Generator → scopes `bot` и `applications.commands`, права: *Manage Roles*, *View Channels*, *Send Messages*, *Embed Links*, *Attach Files*, *Read Message History*. Откройте ссылку и добавьте бота на сервер.
4. **Важно:** в настройках сервера перетащите роль бота **выше** ролей, которые он будет выдавать («Боец» и т. д.), иначе Discord запретит их выдачу.
5. Включите режим разработчика (Настройки → Расширенные), ПКМ по роли → «Копировать ID роли», вставьте ID в `.env`.
6. В папке бота: `npm install`, затем `copy .env.example .env` (Windows) и заполните `.env`.
7. Придумайте длинную случайную строку и задайте её **и боту** (`BOT_API_TOKEN` в `.env`), **и сайту**. Запуск сайта в PowerShell:
   ```
   $env:BOT_API_TOKEN="та_же_строка"; node server.js
   ```
   (cmd: `set BOT_API_TOKEN=та_же_строка` и затем `node server.js`.) Без этой переменной сайт не принимает запросы бота.
8. Запустите бота: `npm start`. Команды `/post` и `/link` появятся на сервере сразу.

`SITE_URL` в `.env` должен быть адресом сайта, доступным с машины бота. Если сайт и бот на одном компьютере, это `http://localhost:3000`.

## Как привязать аккаунт
Сайт → Профиль → **«Привязать Discord»** → появится код → в Discord: `/link код`. После этого роли синхронизируются сами. Отвязка тоже в профиле.

## Модерация предложений
Кнопки доступны: людям с правом «Управление сообщениями» или «Администратор», роли `MOD_ROLE_ID`, роли `ROLE_ADMIN_ID` и администраторам сайта (с привязанным аккаунтом). Автору в личные сообщения приходит ответ, если у него открыты ЛС.

## Настройки (.env)
См. `.env.example`: `POST_REQUIRE_LINK=true` разрешает `/post` только привязанным аккаунтам, `SYNC_NICKNAMES=true` ставит ник равным позывному с сайта (бот не может менять ник владельцу сервера и тем, кто выше его по роли).
Ограничения: фото PNG/JPG/GIF/WEBP до 10 МБ, пауза между предложениями 30 секунд.

## Проверка логики
`npm test`: проверяет расчёт ролей, цикл синхронизации и клиент сайта на заглушках (без Discord).
